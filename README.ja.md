# AR Voxels

AR Voxelsは、仮想環境内で3Dボクセル構造を作成・操作できる、ウェブベースの拡張現実（AR）アプリケーションです。

## デモ
ライブデモは https://code4fukui.github.io/ar-voxels/ でご覧いただけます。

## 機能
- 仮想空間での3Dボクセルキューブの作成と配置
- ボクセルブラシの色の変更
- マウス操作によるボクセル構造とのインタラクション
- AR/VR体験のためのWebXRサポート

## 要件
このプロジェクトは以下のライブラリに依存しています：
- Three.js
- egxr.js
- xrutil

## 使用方法
1. リポジトリをクローンします：
```
git clone https://github.com/code4fukui/ar-voxels.git
```
2. `index.html` ファイルをウェブブラウザで開きます。

## データ / API
このプロジェクトは外部データやAPIを使用していません。
